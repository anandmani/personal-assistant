Personal · Local-first · Open source

Tasks, without the busywork.

Personal Tasks Assistant is a single-user utility that helps its owner read, create, update, complete, and organize Google Tasks through the Google Tasks API. It runs locally on the owner's Mac and is not offered as a hosted service.

Read the privacy policy View the source code

Direct Google access

The client requests Google Tasks access only after the owner signs in and grants consent.

Local credentials

OAuth credentials and saved authorization are kept in owner-only files on the local Mac.

Audited changes

Writes are previewed and recorded locally so task changes can be checked after execution.
