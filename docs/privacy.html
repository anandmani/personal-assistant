Privacy

Privacy Policy

Effective September 18, 2026

Personal Tasks Assistant is a personal-use, single-user application operated by the owner of the anandmani GitHub account. It is not a commercial or multi-user hosted service.

Google user data accessed

With the user's explicit Google authorization, the application accesses Google Tasks data through the https://www.googleapis.com/auth/tasks scope. This may include task-list names, task titles, notes, due and completion dates, status, ordering, hierarchy, and related task metadata.

How the data is used

Google Tasks data is used only to perform user-requested features, including:

  • reading and finding tasks;
  • creating, editing, completing, moving, organizing, or deleting tasks; and
  • creating local backups and audit records so requested changes can be verified.

Google user data is not used for advertising, sold to data brokers, used to determine eligibility or creditworthiness, or used to develop, improve, or train generalized or non-personalized AI or machine-learning models.

AI-assisted processing

When the owner invokes this application through an AI assistant, task data needed to answer the request may be processed by the owner's selected AI service. That processing is governed by the owner's account, workspace settings, and the service provider's applicable privacy terms. The application does not operate an independent remote task-data server.

Storage, retention, and deletion

OAuth credentials, authorization tokens, task backups, and audit records are stored in owner-only files on the local Mac. They are not included in the public source-code repository. Local backups and audit records remain until the owner deletes them.

The owner may delete all locally retained application data at any time and may revoke the application's Google access from the Google Account connections page. Revocation prevents future API access but does not itself delete local backups or audit records.

Sharing and disclosure

The application does not sell Google user data. Data is sent to Google as required to use the Google Tasks API and may be processed by the owner's chosen AI assistant as described above. It is not intentionally disclosed to other third parties except when required by law or necessary to protect the owner or the application from abuse.

Security

Sensitive local files are excluded from Git, stored separately from the source code, and restricted to the local operating-system user. No security measure is perfect, but the application is designed to minimize access and retain only the information needed for its personal task-management functions.

Google API policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes and contact

This policy may be updated when the application's behavior changes. The effective date above will be revised when material changes are published. Questions or deletion requests can be submitted through the project's GitHub issue tracker.
